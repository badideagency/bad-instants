# Sürüm 0.6.0 — Cloudflare Bypass + Yerel Arşiv

## Değişiklikler

- **Cloudflare engeli çözüldü:** Node.js built-in fetch (undici) + gerçek tarayıcı header'ları ile myinstants.com'a erişim sağlandı. `doFetch()` fonksiyonu artık Node.js tarafında çalışıyor, Chromium 99'un Cloudflare JS challenge sorununu aşmış oluyor.
- **Kullandığınız her ses yerelde saklanır:** İndir ile timeline'a koyduğunuz ses, bilgisayardaki arşive (`%APPDATA%\BadIdea\MyInstants\library\`) kopyalanır. Sonraki önizleme ve İndir siteye gitmeden bu kopyadan çalışır; Cloudflare doğrulaması ya da site kesintisi bu sesleri etkilemez.
- Arşiv "Son kullanılanlar" ile sınırlıdır: son 50 ses. Listeden düşen sesin kopyası silinir; favori olan sesin kopyası kalır.
- Favoriye aldığınız ses de aynı kopyayı kullanır; kopya iki kez tutulmaz.
- Düzeltme: Bir ses daha önce "sitede yok" çıkmış olsa bile yerel kopyası varsa artık çalınır.
- Teşhis ekranında Son kullanılanlar için de yerel kopya sayısı görünür.

## Teknik

- Ek paket yok, Node.js 17'de built-in fetch kullanıldı.
- Sıfır server kurulumu, sıfır maliyet.
- Gerçek tarayıcı header'ları (Chrome 120) ile Cloudflare TLS fingerprint simülasyonu.
