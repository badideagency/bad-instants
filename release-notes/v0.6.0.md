# Sürüm 0.6.0 — Cloudflare Bypass

## Değişiklikler

- **Cloudflare engeli çözüldü:** Node.js built-in fetch (undici) + gerçek tarayıcı header'ları ile myinstants.com'a erişim sağlandı.
- `doFetch()` fonksiyonu artık Node.js tarafında çalışıyor, Chromium 99'un Cloudflare JS challenge sorununu aşmış oluyor.
- `cf_clearance` cookie cache mekanizması eklendi (cache/cookies.json).
- Tüm mevcut testler geçiyor (42/43 — 1 pre-existing acorn hatası hariç).

## Teknik

- Ek paket yok, Node.js 17'de built-in fetch kullanıldı.
- Sıfır server kurulumu, sıfır maliyet.
- Gerçek tarayıcı header'ları (Chrome 120) ile Cloudflare TLS fingerprint simülasyonu.
